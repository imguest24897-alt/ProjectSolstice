# Project Solstice

A heavily modified lk2nd fork made to be better (fun fact: the name is literally a oneshot reference XD)

<center><img src="screenshots/screenshot1.png" width="300"><br><i>a alpha build is shown in the screenshot, so expect things to be different maybe</i></center>

This thing is being tested only on a Samsung Galaxy J5 2016 (SM-J510H) and also on a Huawei MediaPad T3 10 (AGS-W09), so some stuff might be broken on other devices

## Known issues :P
### Samsung Galaxy J5 2016 (SM-J510H)
1. Sometimes continuing the boot process causes weird flickering on the screen and then a reboot??? IDK what's causing that LMFAO<br>
NOTE: This only happened for me once, and I couldn't reproduce it again. I don't know how is that even possible!
2. When you try to run stock TouchWiz Android 7, `qdhwcomposer` for some reason infinitely power cycles the display (unless the brightness isn't at the maximum for some reason, but even then it still power cycles it but usually stops after a few minutes)
### Huawei MediaPad T3 10 (both AGS-L09 and AGS-W09)
1. Works and boots only when the engineering bootloader is installed which you can get from the Chinese C233 engineering firmware (which is basically aosp with a bunch of testing apps)
2. The LED apparently sometimes loves blinking instead of being static, I dunno why. (probably not related to project solstice issues but it might be caused by it since that never happened before)
### Project Solstice itself
1. Navigating in the Fastboot Mode menu is kinda janky sometimes
